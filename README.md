# WinForm 电脑定时关机助手 – 需求规格说明书

## 1. 项目概述
开发一款基于 .NET WinForm 的桌面工具，用于自动记录每日首次开机时间，并在工作满指定时长（默认 9 小时 30 分钟）后，自动触发关机倒计时，允许用户延后关机，同时提供系统托盘图标及可视化倒计时窗口。

---

## 2. 功能需求

### 2.1 开机自启动
- 提供设置界面或菜单项，允许用户启用/禁用“开机自动启动”。
- 启用时，将程序自身添加到 Windows 启动项（注册表 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 或启动文件夹）。
- 程序启动时自动最小化到系统托盘，不显示主窗口（除非用户点击托盘图标）。

### 2.2 开机时间记录
- 程序启动后，检查是否存在当日记录文件（例如 `StartTime.log`），若不存在则记录当前时间为“当日首次开机时间”并写入文件。
- 若文件已存在且记录日期为今天，则不再更新（仅保留最早一次开机时间）。
- 文件路径可配置（默认位于程序目录下），格式为纯文本或 JSON，至少包含日期和开机时间。

### 2.3 工作时间监控与关机触发
- 从“当日首次开机时间”开始计时，达到“工作时长”（默认 9 小时 30 分钟，可配置）后，触发**关机提醒**。
- 提醒方式：弹出模态对话框，标题为“下班提醒”，内容包含“您已工作满 X 小时 X 分钟，电脑将在 2 分钟后自动关机。”，同时对话框底部提供延后选项按钮。

### 2.4 延后关机机制
- 关机倒计时为 2 分钟（固定，但可考虑作为配置项）。
- 弹出提醒对话框时，下方提供若干个延后按钮（如“延后5分钟”、“延后10分钟”、“延后15分钟”、“延后30分钟”），按钮数量及对应分钟数可由配置文件定义。
- 点击任一延后按钮后，对话框关闭，重新计算新的关机时间 = 当前时间 + 延后分钟数，并重置关机倒计时（2 分钟）从新时间点开始倒计时。
- 延后操作可多次执行，直到用户主动退出程序或系统关机。

### 2.5 主窗口界面（点击托盘图标显示）
- 窗口尺寸适中（如 400×300），标题显示“下班倒计时”。
- **窗口中间区域**：显示倒计时信息。
  - 正常工作阶段（距离“工作时长”结束还有时间）：显示“距离下班还有 HH:MM:SS”。
  - 进入关机倒计时阶段（即已满工作时长且关机倒计时运行中）：以**红色字体**显示“电脑将在 MM:SS 后自动关机”。
- **倒计时下方**：显示延后操作按钮区域，与提醒对话框的延后按钮保持一致（同样来自配置文件），方便用户快速延后。

### 2.6 系统托盘图标
- 程序启动后即显示在系统托盘（NotifyIcon），右键菜单提供“显示主窗口”、“退出程序”、“开机自启设置”等选项。
- 托盘图标在悬停时（ToolTip）显示当前状态：
  - 正常倒计时阶段：显示“下班倒计时：HH:MM:SS”
  - 关机倒计时阶段：显示“⚠ 关机倒计时：MM:SS”（红色文本无法直接显示，可用“⚠”符号代替）
- 提供额外开关：“在任务栏显示下班倒计时”（选项菜单或配置项）。  
  开启后，任务栏按钮（即主窗口的任务栏条目）上动态显示倒计时文本（通过修改窗口标题或使用任务栏进度/文本扩展），关机倒计时阶段标题变为红色（或添加“⚠”前缀）。

### 2.7 配置管理
- 配置文件采用 JSON 或 XML 格式（如 `config.json`），与程序同目录。
- 可配置项：
  - `WorkDuration`：工作时长（分钟），默认 570（即 9h30m）。
  - `ShutdownCountdown`：关机倒计时时长（分钟），默认 2。
  - `DelayOptions`：延后选项列表（分钟数），例如 `[5, 10, 15, 30]`。
  - `LogPath`：开机时间记录文件路径，默认 `./StartTime.log`。
  - `EnableTrayCountdown`：是否在任务栏（或托盘悬停）显示倒计时，默认 `true`。
- 提供简单的设置窗口（可从托盘右键菜单打开）允许用户修改上述配置，修改后即时生效。

## 3. 用户交互流程

1. 用户开机 → 程序自动启动（如果已启用自启）→ 记录首次开机时间 → 最小化到托盘。
2. 正常工作期间，用户可点击托盘图标打开主窗口查看倒计时。
3. 当工作满规定时长，弹出提醒对话框，同时主窗口自动切换到“关机倒计时”红色显示。
4. 用户可选择延后，点击延后按钮后对话框关闭，倒计时重置；若倒计时归零且无延后操作，程序执行系统关机命令（`shutdown -s -t 0`）。
5. 关机前若用户主动退出程序，则取消已计划的关机（调用 `shutdown -a`）。

## 4. 非功能性需求

- **稳定性**：记录文件读写需处理并发（避免多实例同时写入），建议使用互斥锁确保单实例运行。
- **兼容性**：支持 Windows 7/10/11，.NET Framework 4.7.2 或 .NET Core/6+。
- **资源占用**：低内存和 CPU 占用，定时器精度 ±1 秒即可。
- **异常处理**：文件读写失败、关机命令执行失败时应有友好的错误提示，并记录日志（可选）。
- **安装部署**：提供 ClickOnce 或 MSI 安装包，或简单可执行文件 + 配置文件。

## 5. UI 草图（文字描述）

- **主窗口**  
  - 顶部：程序标题 + 关闭按钮。  
  - 中部：大号字体显示倒计时（正常为黑色，关机倒计时为红色）。  
  - 底部：一行延后按钮（与配置一致），按钮间距均匀。  
- **提醒对话框**  
  - 模态，居中弹出，显示提示文本 + 延后按钮（与主窗口底部一致）。  
- **托盘右键菜单**  
  - “显示主窗口”  
  - “设置” → 打开配置界面  
  - “开机自启（开/关）”  
  - “退出”

## 6. 技术实现建议

- 使用 `System.Windows.Forms.Timer` 实现每秒更新倒计时。
- 使用 `Microsoft.Win32.Registry` 或 `Environment.GetFolderPath(Environment.SpecialFolder.Startup)` 管理自启。
- 使用 `System.Diagnostics.Process.Start("shutdown", args)` 执行关机/取消。
- 使用 `NotifyIcon` 实现托盘，其 `Text` 属性可设置悬停提示，`BalloonTip` 可用于提醒。
- 配置文件使用 `System.Text.Json` 或 `Newtonsoft.Json` 读写。
- 确保单实例运行：使用 `Mutex` 或 `Process.GetProcessesByName`。

## 7. 验收标准

- [ ] 开机自启功能正常，程序随系统启动并记录当日最早开机时间。
- [ ] 到达工作时长后，弹出提醒对话框，倒计时准确。
- [ ] 延后按钮可正常重置倒计时，多次延后有效。
- [ ] 主窗口倒计时显示正确，关机阶段变为红色。
- [ ] 托盘图标悬停提示显示当前倒计时状态，可配置开关。
- [ ] 配置修改即时生效，无需重启程序。
- [ ] 关闭程序时取消已计划的关机。
